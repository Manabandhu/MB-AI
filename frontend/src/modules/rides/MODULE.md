# Rides

Owns ride discovery, offers, requests, seats, participants, history, ratings, location sharing, safety state, and ride management.

The first Stitch batch routes `/rides`, `/rides/search`, `/rides/map`, `/rides/filters`, and `/rides/offer` share `screens/RidesScreen.tsx`, `ridesFallbacks.ts`, and the read-only demo endpoint `GET /api/v1/rides/screens/{screenId}`.
