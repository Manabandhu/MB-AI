# Layout & Responsive Rules (DS-03)

## Spacing System
- **Base Unit**: 4px
- **Grid**: 8px (2x base)
- **Gutter**: 16px (mobile)

## Responsive Breakpoints
- **Compact**: 320px - 430px (Phones)
- **Foldable Cover**: Single column centered.
- **Foldable Unfolded**: Two-pane master-detail layout.

## Accessibility
- **Touch Targets**: 44px min, 48px preferred.
- **Contrast**: WCAG 2.2 AA compliant.
- **Motion**: Reduced motion support via CSS media queries.
